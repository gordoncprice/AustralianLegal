# Repository rules

- Use Australian English.
- Never invent legal citations, quotations, provisions, cases, URLs, or source content.
- Prefer current primary and official sources; record when and how currency was checked.
- Analyse Commonwealth, state, territory, applied, uniform, and overlapping regimes separately.
- Preserve an independent legal review before delivery of substantive research.
- Provide legal research information, not legal advice, and expose material uncertainty.
- Add executable code only for a necessary deterministic task; do not add incomplete scaffolding.
- Keep changes and commits small and reviewable. Never force-push or alter `main`.
- Run the repository validation and relevant behavioural evaluations before completion.
